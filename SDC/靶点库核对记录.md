## 一、旧标准适用性及针对性修订

| 实验 | 旧的“缺陷—修复—改善”标准 | 原因及新标准的着眼点 |
|---|---|---|
| E1 | 不直接适用 | 导读目标是正确理解结构／运行／数据流；改为结构与边界、理解依据、源码＋运行核实 |
| E2 | 部分适用 | 架构问题可能是变化成本；保留具体问题、相关4+1视图、两案权衡及局部可运行验证 |
| E3 | 直接适用 | 真实缺陷可形成规格—失败—修复—回归；明确AI核对与目标方法覆盖率 |
| E4 | 基本适用 | 坏味道不必是功能错误；强调模式效果／代价和改前改后行为保持 |
| E5 | 不直接适用 | 计划不是实现；核实影响关系、边界、风险和测试计划可执行性，不提前做E6 |
| E6 | 部分适用 | 新功能缺失不等于旧代码违规；评规格、兼容实现、规范取舍及功能／非功能验证 |
| E7 | 部分适用 | 新AI能力不必有坏初版；评普通／LLM分工、独立事实验收、失败与降级，成绩不等于放行 |

新细则保留三个维度，每次100分（30／30／40），逐实验给出子项和完整／部分／缺失证据判分。课程总成绩30%网络课堂＋70%项目实践及过程要求不变。正文、学生手册和E1–E7当前入口已引用新细则；旧大纲Word及历史证据未改写。

## 二、实验方案按新标准评审

| 实验 | 目标与新要求是否对应 | 现有教师产出／准备限制 |
|---|---|---|
| E1 | 是：模块、生成边界、选定链路和本人核实 | 图、工具及历史真实查询可参考；每个学生仍须核实自己的候选链，不借用商品查询证明其他业务 |
| E2 | 是：两案权衡＋一个实际接缝验证 | 旧LayerRules及未实施两案不是当前满额产出；候选计划已明确测试与局部改动 |
| E3 | 是：规格、红灯、最小修复、AI记录、回归／覆盖率 | 积分示例有证据；当前候选有改前观察，但修复须按各题独立执行 |
| E4 | 是：特征测试、实际重构、模式四要素与代价 | 促销示例可参考；不强迫所有题套策略，也不只凭测试全绿判设计改善 |
| E5 | 是：影响清单、排除方案、风险与可执行验证计划 | 不再要求产品改动；源码工具测试不能替代所选业务的关键影响核实 |
| E6 | 是：新需求、兼容实现、规范取舍及相应层次证据 | 预警教师示例仍缺下单告警边界的直接断言；新候选未实现，按逐题计划完成，不冒称现成答案 |
| E7 | 是：普通／LLM实现、事实边界、独立评测和结论 | 六种新业务缺完整教师题集及真实模型结果；商品查询历史31/32不能替代。已去除强制造有缺陷初版的要求 |

**适配结论不是“所有现有产出已达标”。** 本轮完成的是评分、方案和候选／计划的对齐；准备时间、学生试做、实现质量及真实模型表现尚不能从文档推断。E7-01／02需要已有隔离业务环境，E6-04／05需要隔离Mongo集成；缺少时可完成离线部分，但不能声称相应运行分已满足。
