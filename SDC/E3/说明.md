# E3：规格先行与 AI 结对编程

示例按《示例分支工作流程指南》组织：每个示例是从本分支分出的独立分支 `exp/e3-<NN>`，彼此没有先后次序，也不合并；`NN=00` 为教师演示示例。靶点、验收准则和对照结果见对应 Issue（标签 `E3`）。

| 示例 | 靶点 |
|---|---|
| E3-00 | 教师演示：下单使用积分与赠送积分分别记录 |
| E3-01 | 优惠券门槛按数值比较 |
| E3-02 | 购物车合并时更新修改时间 |
| E3-03 | 批量删除属性按各自分类扣减计数 |
| E3-04 | 修改属性时同步迁移分类计数并保证原子性 |
| E3-06 | 商品属性分类 ID 的参数校验 |
| E3-07 | 无效地址更新不清空已有默认地址 |

复现：`git checkout exp/e3-<NN> && SDC/compare.sh E3-<NN>`（JDK 17；数据库用例需要 `SDC/environment/compose.yml`）。规格先行的示例应当改前失败、改后通过。
