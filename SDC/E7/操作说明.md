# E7 操作说明

当前评分以[本实验细则](../课程考核方案.md#rubric-e7)为准；个人题目执行[Cursor计划](../Cursor候选靶点产出计划.md)对应编号。

当前学生选题见[合并后的业务设计](../教师候选靶点库.md#e7-business)。下文保留教师商品查询实现与历史验证供参考；其测试数和模型成绩不代表学生所选业务已验收。

> 学生先按[最简操作手册](../学生操作手册.md)完成本次任务；本页是需要时查阅的技术细节，不新增环境安装、报告或评分要求。统一运行环境由教师/助教按[环境准备](../教师环境准备.md)提供。

要求 JDK 17、Maven。以下命令从包含 `mall/` 的仓库根目录执行；`rtk` 是本仓库规定的命令前缀。IDEA 打开 `mall/pom.xml`，Project SDK 与 Maven Runner 均设为 17。

## 离线测试

```sh
rtk proxy mvn -f mall/pom.xml -pl SDC/E7 -am test
```

SDC 父模块已单独启用实验测试；不要全局添加 `-DskipTests=false`，以免同时运行原 portal 的中间件集成测试。无需模型凭据、数据库或 Redis。测试需要允许本机 loopback HTTP 监听。IDEA 运行 `ProductQueryTest`、`LlmClientTest`、`QueryEvaluationTest`。另运行 `CursorCliLlmClientTest` 验证本地 Java 替身进程的协议、权限、失败及超时（不会调用真实 Cursor 模型）。测试报告在 `mall/SDC/E7/target/surefire-reports/`。

## 真实查询演示

使用课程现成的 MySQL、Redis、MongoDB、RabbitMQ环境。若使用 `SDC/environment` 配置，在IDEA或命令进程环境变量设置 `SPRING_CONFIG_ADDITIONAL_LOCATION` 为该文件的绝对 `file:` 路径，或相对当前工作目录的正确路径；不要误连默认3306。演示会启动真实 portal Spring 上下文，临时 HTTP 端口仅绑定 127.0.0.1，并关闭 RabbitMQ simple/direct 消费者自动启动，避免消费排队的订单消息；结束后关闭，不新增产品 API。

```sh
rtk proxy mvn -f mall/pom.xml -pl SDC/E7 -am test -DskipTests=true -Pe7-run '-Dexec.args=existing 小米'
```

普通查询不需要模型配置。LLM 模式在运行环境设置：

- `LLM_BASE_URL=https://provider.example/v1`
- `LLM_MODEL=<服务端模型ID>`
- `LLM_API_KEY` 或 `LLM_ACCESS_TOKEN` 二选一，使用 IDE 环境变量或安全的终端输入，不把真实凭据写入源码/命令历史/报告。

```sh
rtk proxy mvn -f mall/pom.xml -pl SDC/E7 -am test -DskipTests=true -Pe7-run '-Dexec.args=llm "查询名称包含小米且价格小于3000且库存小于101的商品"'
```

IDEA 运行 `QueryDemo.main`，程序参数为 `existing 小米` 或 `llm "价格低于100"`，classpath 选 SDC E7。断点依次放在 `LlmProductQueryService.query`、`LangChain4jLlmClient.generate`、`ExistingProductQueryService.query`、`PmsPortalProductServiceImpl.search`。注意普通模式的“价格低于100”只是名称关键词。

## 使用本机 Cursor 登录

确认已安装 `cursor-agent` 和 `rtk`，并通过官方 `cursor-agent login` 在本机完成登录。无需复制 token。设置 `LLM_PROVIDER=cursor` 和 `LLM_MODEL=grok-4.7-high-fast`（可改为当前登录账号可用的模型 ID）；不要把 Cursor token 填入 API key 或 API access-token。

```sh
rtk proxy env LLM_PROVIDER=cursor LLM_MODEL=grok-4.7-high-fast mvn -f mall/pom.xml -pl SDC/E7 -am test -DskipTests=true -Pe7-run '-Dexec.args=llm "查询名称包含小米且价格小于3000的商品"'
```

IDEA 在运行配置中设置相同环境变量。Cursor 适配器自行创建空临时工作区并拒绝所有工具，60 秒超时；登录失效时由 CLI 认证失败，查询返回 `UNAVAILABLE`，请通过官方 CLI 重新登录。默认 `openai-compatible` 路径继续支持前述 base URL / model / API 凭据配置。

## Java 回归评测

使用相同真实数据库和模型配置。评测只把题目文本发给查询服务，不把期望 ID/状态发给模型；检查状态和排序后的精确 ID 集（首 100 条）。全部匹配只标为 `REGRESSION_PASSED`，失败退出码 1；不是独立模型准确率或发布放行。不要覆盖历史结果。

```sh
rtk proxy mvn -f mall/pom.xml -pl SDC/E7 -am test -DskipTests=true -Pe7-run -Dexec.mainClass=com.macro.mall.sdc.e7.QueryEvaluation '-Dexec.args=mall/SDC/E7/evaluation/readonly-regression.json mall/SDC/E7/target/readonly-regression-result.json'
```

IDEA 可运行 `QueryEvaluation.main`，工作目录设为仓库根目录。模型不可用不会算作正确拒绝；数据库故障会终止本次运行，不能据此声称评测通过。题目超过 100 个命中商品时，应明确改成分页期望后再扩展评测，当前题集只有样例库规模。

历史 Python 实现已在 Java 替代测试通过后移除，保留历史题集、结果和说明。本次 Cursor 真实评测第二套为31/32（正常19/20、对抗8/8、分布外4/4），保留一条模型协议偏离导致的误拒绝。详见[迁移验收](../迁移验收.md)。现已公开的 `java-holdout-1.json`、`java-holdout-2.json` 后续只能作回归题使用；重跑请输出到 `target/` 下，勿覆盖首次证据。
