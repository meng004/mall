## 脚手架里的共用部分

各示例都要用、因此放在本分支的内容：

- `mall-portal/pom.xml`：`langchain4j-open-ai` 依赖。
- `mall-portal/src/main/java/com/macro/mall/portal/llm/`：模型访问层 `LlmClient` 及 OpenAI 兼容实现、Cursor CLI 实现和 Spring 配置。未配置时调用即抛出“LLM is not configured”，由各业务显式降级。
- `mall-portal/src/test/java/com/macro/mall/sdc/e7/EvaluationSupport.java`：评测器公共部分（入参防泄漏、脱敏、放行阈值、未评分行、报告与退出码、教学库预检、历史回放分类）。评测器属于验收工具，不是产品代码，所以放在测试源码里。
- 对应测试：`LlmClientTest`、`CursorCliLlmClientTest`、`EvaluationSupportTest`，全部离线（本地 HTTP 替身与假进程），不调用在线模型。

各示例自己的业务服务、评测器、测试和题集（`SDC/E7/evaluation/E7-<NN>/`）只放在各自分支。

## 在线评测（各示例分支）

评测器在 `mall-portal` 测试源码里，入口是 `CandidateE70<N>Evaluation.main(题集, 报告)`。E7-01 至 E7-06 用 `EvaluationSupport.cursorClient` 直接构造 `CursorCliLlmClient`。E7-00 的 `QueryEvaluation` 从 Spring 容器取 `LlmClient`。

- `MALL_LLM_CURSOR_CMD`：`CursorCliLlmClient` 读取，按空格拆成命令。未设置或空白时用 `cursor-agent`。例如 `/home/<用户>/.local/bin/cursor-agent`。
- `LLM_MODEL`：`EvaluationSupport.modelName()` 读取，作为 Cursor CLI 的 `--model`。未设置或空白时用 `grok-4.7-high-fast`。`LlmConfiguration` 也读这个环境变量（属性 `mall.llm.model`）；`provider` 为 `cursor` 且模型名为空时同样用 `grok-4.7-high-fast`。
- `LLM_PROVIDER`：只由 `LlmConfiguration` 读取（属性 `mall.llm.provider`），默认 `openai-compatible`。值为 `cursor` 时使用 `CursorCliLlmClient`；值为 `openai-compatible`，且 `LLM_BASE_URL`、`LLM_MODEL` 以及 `LLM_API_KEY` 或 `LLM_ACCESS_TOKEN` 有值时，使用 `LangChain4jLlmClient`；`openai-compatible` 但这些值不齐时，调用抛出 `LLM is not configured`；其他值抛出 `Unknown LLM provider`。`EvaluationSupport.cursorClient` 不读 `LLM_PROVIDER`。

没有模型可用时，离线测试能验证超时、非法输出与显式降级的处理：`LlmClientTest` 使用本地 HTTP 替身，`CursorCliLlmClientTest` 使用假进程。这些测试不能证明模型质量。在线评测会消耗所用模型服务的额度。

参考命令（本脚手架已离线核对 `mvn -B -o -Ddocker.skip=true -pl mall-portal -am -DskipTests install` 与 `mvn -B -o -pl mall-portal test-compile`：只编译，不运行测试，不调用模型。`docker.skip` 用来跳过 `package` 阶段的镜像构建。下一行的 `exec:java` 会运行 `CandidateE704Evaluation` 并调用模型；该类不在本分支，本次没有执行）：

```sh
mvn -o -q -pl mall-portal -am -DskipTests install
mvn -o -pl mall-portal test-compile org.codehaus.mojo:exec-maven-plugin:3.5.0:java \
  -Dexec.classpathScope=test -Dexec.mainClass=com.macro.mall.sdc.e7.CandidateE704Evaluation \
  -Dexec.args="../SDC/E7/evaluation/E7-04/acceptance.json target/e7-04-report.json"
```

在线结果只说明那一次调用；没有独立人工核对时，正式结论不采用“放行”。
