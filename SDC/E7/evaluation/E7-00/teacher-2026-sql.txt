E7-00 教师题集 2026 秋：20 道正常题 SQL 与执行输出
编写日期：2026-10-10
连接：MySQL 127.0.0.1:13306，库 mall，字符集 utf8mb4（SET NAMES utf8mb4，客户端 --default-character-set=utf8mb4）
账号：课程 compose 中的 mall 应用账号（口令不写入本文件）
执行方式：docker exec 进入容器 sdc-classroom-mysql-1 的 mysql 客户端，只读 SELECT
复核：同一批 SQL 连续执行两遍，两次输出全文一致。空结果题另做单独一轮抽查，仍无数据行。

mysql 批处理模式对空结果集不打印列头，因此空结果的执行输出记为「（无数据行）」。
t26-n18 的 SQL 源码中 LOCATE 参数写成两个反斜杠（'\\'），在 MySQL 默认字符串转义下表示一个反斜杠字符。
