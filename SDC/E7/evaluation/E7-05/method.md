# E7-05 标注方法

独立人工核对尚未进行。

标注方法：按计划中的书面规则构造并判定。不读取实现、提示词或测试，不用模型输出当真值。

## 真值来源

计划示例：颜色允许红/蓝，容量允许 128GB/256GB，描述“红色，128G”得到红和 128GB。全角折半角、尺寸去掉“号/码”、蓝色→蓝写在 facts 的事先规则里。属性 id 21、22、23 是教学白名单，不是从商品表读出的生产 id。

## 精确匹配

两版输入相同。精确匹配 state、按 attributeId 升序的 values（id、规范化 value、evidence），以及 unknownIds 集合。evidence 必须是原文连续片段，可以和规范化后的 value 不同。

## 对抗与分布外

品牌惯常容量、绿色、1TB、三百、128MB 都不得进入 values。保存、属性 99 或 999 不得出现。没有合法值时 NEEDS_INPUT，unknownIds 覆盖本次白名单。分布外句子不抽取，也不执行写入。

## 未决

规格示例只写了 G=GB 和红色→红。全角、尺寸后缀和蓝色→蓝是本集声明的事先规则；未声明的单位保持未知。
