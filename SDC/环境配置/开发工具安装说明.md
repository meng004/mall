# 开发工具安装说明（Windows）

一条命令装好 E1 需要的五个工具：Git、OpenJDK 17、Maven、IntelliJ IDEA、Claude Code。已经装过的会自动跳过，可以重复运行。

## 1. 运行脚本

1. 下载本目录的 [`install-dev-tools.ps1`](install-dev-tools.ps1)。
2. 在文件所在文件夹空白处按住 Shift 右键 →「在此处打开 PowerShell 窗口」（或打开终端后 `cd` 到该目录）。
3. 执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\install-dev-tools.ps1
```

安装过程中会弹出几次 **用户账户控制（UAC）** 窗口，点「是」。IDEA 约 1 GB，下载时间取决于网速。

## 2. 脚本做了什么

| 工具 | 来源 | 说明 |
|---|---|---|
| Git | winget `Git.Git` | Claude Code 在 Windows 上依赖 Git Bash，所以最先装 |
| OpenJDK 17 | winget `Microsoft.OpenJDK.17` | 微软构建的 OpenJDK；脚本自动设置 `JAVA_HOME` |
| Maven 3.9.9 | Apache 官方归档 | winget 没有官方包；解压到 `%USERPROFILE%\tools`，设置 `MAVEN_HOME` 和 `Path` |
| IntelliJ IDEA | winget `JetBrains.IntelliJIDEA` | 2025.3 起不再分 Ultimate/Community，学生可用教育许可 |
| Claude Code | 官方 `claude.ai/install.ps1`；失败时改用 npm 国内镜像 | 官方安装器从 Google 存储下载，国内常连不上；回退时脚本会先装 Node.js LTS，再从 npmmirror 安装 |

环境变量只写入**当前用户**，不改系统级设置。

## 3. 验证

**关闭所有终端和 IDEA，重新打开一个 PowerShell**，逐条执行：

```powershell
git --version
java -version
mvn -version
claude --version
```

`java -version` 和 `mvn -version` 里显示的 Java 版本都必须是 **17**。

## 4. 下一步

1. 按[DeepSeek配置说明](DeepSeek配置说明.md)配置 Claude Code。
2. 打开 IDEA → Open → 选 `mall/pom.xml` → 作为 Maven 项目打开。Project SDK、Maven Importer JDK、Maven Runner JRE 都选 17。
3. 按[学生操作手册](../学生操作手册.md)跑第一个测试。

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| 提示「未找到 winget」 | 在 Microsoft Store 搜索安装「应用安装程序」(App Installer)，Windows 10 老版本常见 |
| 提示「无法加载，因为在此系统上禁止运行脚本」 | 没加 `-ExecutionPolicy Bypass`，按第 1 节的命令原样执行 |
| `java -version` 不是 17 | 机器上还有别的 JDK 排在 `Path` 前面。在「编辑账户的环境变量」里把 JDK 17 的 `bin` 移到最上面 |
| `mvn` 不是内部或外部命令 | 没有重开终端。仍不行就检查用户 `Path` 里有没有 `%USERPROFILE%\tools\apache-maven-3.9.9\bin` |
| Maven 下载失败 | 校园网可能拦截了 archive.apache.org，换手机热点重跑脚本，已装好的工具会跳过 |
| 安装 Claude Code 时报 `failed to fetch version ... ECONNREFUSED` | 官方下载源连不上。脚本会自动改用国内镜像；手动处理执行 `npm install -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com`（需 Node.js 22+）。若错误里的地址是 `127.0.0.1`，是系统设置了已关闭的代理，删掉 `HTTP_PROXY`/`HTTPS_PROXY` 环境变量 |
| `claude` 找不到 | 重开终端后再试 |
| winget 某个包装失败 | 脚本会停在出错的工具并显示退出码。处理后重跑即可，已装的会跳过 |

macOS 用户不用这个脚本：用 Homebrew 执行 `brew install git openjdk@17 maven` 和 `brew install --cask intellij-idea`，再执行 `curl -fsSL https://claude.ai/install.sh | bash`。
