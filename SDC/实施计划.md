# SDC Java 迁移实施计划

> 执行方式：superpowers:subagent-driven-development；按任务实施并独立复审。

**Goal:** 在原 mall 工程内提供 E1–E7 Java 教学与复现入口。
**Architecture:** 产品实现留在 mall，SDC 聚合实验；E7 双查询实现共用真实数据库查询，LLM 经薄访问层调用 LangChain4j。
**Tech Stack:** Java 17、Maven、JUnit 5、Mockito、LangChain4j。
**Spec:** [SDC迁移设计.md](SDC迁移设计.md)

## 全局约束

保留现有未提交产品修复；不提交或推送。所有终端命令以 rtk 开头。历史证据不改写。E7 只读。普通测试离线，无 Python 运行依赖。
