# 教学资料

软件设计与规范 2026 秋。这里的资料与教师上课所用完全相同，不另设学生版：课件备注里有讲稿、题目答案与判定依据，实验课有预习题回顾。公开它们，是希望你在课前、课后都能看到每一讲为什么这样安排、每道题考的是什么，用来预习、复习，也欢迎据此对课程提出意见。

| 路径 | 内容 |
|---|---|
| `课件/` | 理论课 T1–T7、实验课 E1–E7 课件，含全部备注（讲稿：定义、代价、判定、权衡；签到与预习题答案） |
| `软件设计与规范-教学大纲-2026秋季修订版（棕地项目）.docx` | 现行教学大纲：课程目标、学时与考核 |
| `教案/` | 三份 2026 秋教案（软卓、软工、船本），每次课的教学目标、重点难点、教学过程、互动题与实验要求 |
| `课件大纲.md` | 从教案到课件的设计：每讲的页组、时间分配、取材与衔接 |
| `理论章节.md` | 理论课章节与阅读文献 |
| `设计记录/` | 制作课件时定下的事项与理由（`grill-t2t7.md` 理论课、`grill-labs.md` 实验课） |
| `附录-AI协作与产出验收规范.md` | AI 协作与产出验收规范 |

想了解教学目标，看教学大纲与各次课教案的"教学目标"一行；想了解设计思路，看 `课件大纲.md` 与 `设计记录/`。实验方案、考核方案、学生操作手册在上一级目录：[`课程实验方案.md`](../课程实验方案.md)、[`课程考核方案.md`](../课程考核方案.md)、[`学生操作手册.md`](../学生操作手册.md)。各实验的脚手架在 `exp/E<n>` 分支，教师示例在 `exp/e<n>-<NN>` 分支，说明与验收见对应 Issue。
